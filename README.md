# IM800Emu

An implementation of the IM800 fantasy ISA in a PC-like computer.

This project is written in C# using .NET 10 and is designed to be easy to
understand and extensible.

It includes an integrated debugger using the console alongside the main emulator
window, accessible at any time.

## Building

Requirements:
- .NET 10 SDK

Build the project: `dotnet build`

Publish a release build: `dotnet publish -c Release`

This project is developed on Windows 11 and Ubuntu 26.10, and should run
anywhere .NET 10 and Raylib is supported.

## Usage

`IM800Emu <program file> [symbol file]`

### Symbol File

The integrated debugger supports using symbol files generated by IM800Asm.

## Emulated Computer

The emulated computer is designed to be similar to an IBM PC, but with the IM800
processor and custom components. By default, the machine includes:

- IM800 processor at 4 MHz, with a 16-bit data bus
- 256 KiB of RAM
- A CGA-like video adapter, with 80x25 text mode graphics
	- Additional bitmap graphics modes are planned
- An interrupt-driven keyboard using IBM Set 1 scancodes

In the future I intend to add devices such as:

- High-resolution timer
- Disk controller
- DMA controller

### Memory Map

```
0x000000-0x1FFFFFF: Program ROM (size depends on program file)
0x200000-0x203FFFF: RAM (256 KiB)
0x400000-0x4000FFF: Video RAM (4 KiB)
```

### I/O Map

```
0x00-0x03: Video Processor
- 0x00: Video Mode
	- 0: 80x25 Text Mode
- 0x01: Video State
	- b0: Display Enabled
	- b1: Cursor Enabled
- 0x02: Cursor Row
- 0x03: Cursor Column

0x04-0x07: Keyboard
- 0x00: Key Buffer (read-only)
- 0x01: Status
	- b0: Interrupts Enabled
```

## Debugger

The integrated debugger can be accessed at any time by pressing `Ctrl+P` in the
standard input.

The debugger supports inspecting registers, memory, and single-stepping the
computer.

I plan to support breakpoints, watchpoints, and writing values in the near
future.
